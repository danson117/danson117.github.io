Briefing & Read & Sign

Attach one or more Word, Excel, or PDF materials, choose the people, then record who has seen or signed with their 6-digit staff PIN. When everyone is done the item turns green. Anyone still open stays outstanding on Training One View (Material link only — status is not changed there).

Admin PIN vault

Shows Name List people as Custom PIN set or Still default (staff number until first change). Admins never see a PIN or hash. The only action is Remove / reset, which deletes the custom PIN so the next sign uses the staff number again and then forces a new 6-digit PIN. Requires the HX Unlock admin password.

  • Click Refresh list after Unlock with the admin password.

Confirm with PIN

First-time default accepted. Choose a new 6-digit PIN that is not your staff number. Signature is recorded only after the new PIN is saved.
