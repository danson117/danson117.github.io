This page stores course master data in this browser (same idea as OCG Name List). Code is the unique key. Type is Online or Classroom; leave blank until you set it. Name is the course / certification name.

Award, Issued By, and Description are course-level fields. Interval is how often the course is done (e.g. 12 months, 24 months, annual). Courses do not have an expiry date — staff due / expire dates stay on CT / UAL / Mandatory. All-source Training reads this list: a name typed here fills Mandatory rows that only have a Course Code.
