This page stores course master data in this browser (same idea as OCG Name List). Code is the unique key. Type is the method: Online, Classroom, or TBD. Name is the course / certification name. Recurrent is the recurrent course code for that initial course. Applicable To is who the initial course is for.

Course List is independent of Training One View CSV ingest. Loading CT Reminder, Mandatory, or UAL does not delete or replace these rows. New codes from the board only add or fill empty fields. If a CSV has the same code with a different name (or the same name with a different code), Training One View asks which to use — it does not silently overwrite this list. Code-only CSV rows use the Name typed here.

Award is carried from the CT Reminder CSV column headed Award (stored beside Issued By and Description). This page does not define what Award means in LMS terms — it keeps the field as imported. Interval is how often the course is done (e.g. 12 months, 24 months, annual). Courses do not have an expiry date — staff due / expire dates stay on CT / UAL / Mandatory.

Related lists the other course code when two codes are variants (the same code plus CT, REV, or T, or Operator and Trainer) or the titles are very similar even if the codes differ. Both rows list each other, separated by commas when there is more than one. Suggestions fill in automatically. Edit a cell to keep your own text.
