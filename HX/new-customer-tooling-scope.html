7. Alternative tool 點先算「得」（紀錄要點）

加入日期 2026-09-14。Acceptability 唔係 QA 口頭話得。技術判斷喺 TS；QA 確認證據齊、可追溯。MOLIT／客最後先 accept。

方法 評估人 QA 角色 Authority／MOLIT
OEM Equivalency Airbus／Tool OEM Review evidence 最強
Vendor Equivalency Letter Tool supplier Verify validity 強
TS Technical Assessment TS Engineer Witness／Accept 常見
Practical Trial／Validation Production + TS Witness／Record 常見
Historical Usage Production Review only 最弱

四種做法（簡）

  • OEM 證明： AMM 要 PN A；vendor／Airbus 文件寫 PN B equivalent。TS 收證據，QA review。
  • TS assessment（最常見）： 功能比較（SWL、高度、interface 同等或更好）。TS Engineer 簽名就可以交 QA。
  • Procedure validation： AMM 只寫 support brake、冇指定 PN。TS + Production 證明唔跌、load 受控、夾到、入到 access、跟到 AMM sequence。
  • Demonstration： Production 用 alternative tool 真做一次 A380 brake change；影相、load check、risk、observation。TS 出「跟 AMM 做完」報告。客最 buy。

QA 唔決定刀得唔得

  • QA 問：證據喺邊？assessment、TS 簽名、risk、reference 有冇。
  • QA 唔自己判斷 brake lifting kit 技術上得唔得。
  • Lo Kwok Chuen 問「alternative tool 可唔可以換 A380 brake」→ 唔應該問 QA，應該問 TS 有冇 equivalency／AMM 證明。

鏈： AMM requirement → TS assessment → alternative tool validation → QA review → Customer／MOLIT acceptance。
