新客／新機型／新引擎 — Tooling scope

日常工作流程紀錄 · Tech Service 先出清單 · 再確認庫存 · Production 處理缺口

點解有呢頁： 記低日常點做，之後可以喺 HX 翻睇。第一條流程：有新客戶、新機型或新引擎要做維修時，要確保 tooling 齊同符合該次工作範圍。

來源：你口述嘅 TS 步驟，加 YS Fung 電郵（A380 Korean Air / B767 Raya tooling list）。未寫死嘅崗位用橙色底，方便之後改。

1. 幾時啟動

會啟動

  • 新客戶（例如 Korean Air A380、Raya B767）
  • 新機型，或同一客加新機型
  • 新引擎（同一機型換咗引擎系列）
  • QA 要求 TS 出 tooling scope

呢頁未覆蓋

  • 日常已經有、只係借刀／補數
  • 授權／訓練（見 Authorization Training Process）
  • 採購落 PO 之後嘅收貨細節

2. 流程

QA

1. 提出要求

  • 新客／新機／新引擎要做維修
  • 要求 TS 出 tooling scope
→
Tech Service (TS)

2. 睇 check sheet

  • A check 同／或「樓下」線上工作
  • 逐張 check sheet 抽出要準備嘅 tooling
  • 最常見：換轆／換掣（wheel / brake R&I）
→
Confirm 庫存

3. 有冇呢啲刀

  • 對 HAECO inventory
  • 分：庫有／缺／可借
  • 崗位見第 5 節（未完全定死）
→
Production

4. 缺口點補

  • 審所需清單
  • Budget / CAPEX 買
  • 或 tool loan 理由，補 gap

TS 負責「要咩刀」。確認「有冇」同「點買／點借」係下一步，唔好停喺清單。

3. TS 實際做咩

Check sheet → tooling 清單

  • 定工作範圍：A check，定樓下（線上／停機坪常見工，例如換轆換掣）。
  • 攞齊該機型／引擎、該 check 嘅 check sheet。
  • 每張 sheet 列所需 special tooling，合成一份 required tooling list。
  • 最常、最優先：Wheel / Brake R&I（換轆、換掣）。
  • 可先出 HAECO inventory 入面已有嘅 generic 清單（A380 電郵就係咁）。
  • 引擎要寫清楚系列（例如 B767-300F / CF6-80C2），同埋做到邊個 FH／FC／MO interval。

4. 有冇刀 — 分岔

庫存有冇所需 tooling？

對完 HAECO inventory 之後。

有 — 可以用

列入 available。Production 知到開工前刀喺邊。唔使為呢項開 CAPEX。

冇 — 要補 gap

Production 檢視清單：開 budget／CAPEX 買，或者寫 tool loan 理由向外借，直到 outstanding gap 清晒。

5. 實例（電郵）

個案 TS 要出咩 目標時間
A380 · Korean Air HAECO inventory 已有嘅 A380 generic tooling，加 wheel / brake R&I tooling。 兩星期內（電郵寫 on or before 10 September）
B767 · Raya B767-200（電郵寫 PW-80A，引擎型號要再核）同 B767-300F / CF6-80C2；範圍做到 750 FH / 21 FC 及對應 MO interval 所需 tooling。 A380 清單完成後兩個月內

電郵：Based on QA request, TS to prepare tooling scope。Production may review the required tool list and prepare budget／CAPEX，或 justification for tool loan。

6. 角色同未定點

角色 做 未定／唔做
QA 因新客／新機／新引擎提出 tooling scope 要求。 唔代替 TS 讀 check sheet。
Tech Service (TS) 第一步。按 A check 或樓下工作，睇晒 check sheet，出所需 tooling 清單（包括換轆換掣）。 唔負責最後話「庫有、可以開工」——要交去 confirm。
Confirm 庫存（Tool store / Inventory？） 對清單：每項有／冇／可借。 你講「交俾可以 confirm 有冇嘅人」。電郵未寫死部門名。係 tool store、inventory 定 Production 自己對？之後補。
Production 審 required tool list；缺口用 CAPEX 買，或 tool loan 補。 未有清單之前唔好估預算。
