    When Home and Current are the same code and the last character is 1, 2, 3, or 4, Team follows that digit unless a crew code is already stored. A last character of 5 or X stays TBD. Crew codes such as 1P, E1, D1, and 00 are the Team value. If Home and Current disagree with a new crew file, Team stays as it is until you choose. A Team value does not change CG / PAX.

    OCG = CG + PAX (the total). A person is CG or PAX only. PAX = already marked PAX on the roster, or on the Crew List (including FLS and RF). CG stays CG. A Team number is only a team number and does not make someone PAX, so CG can have a Team number. Certifiers = Licensed Engineer / Assistant Licensed Engineer / Controller / Duty in Charge (including Deputy DIC and OCG PAX / CARGO / UPS DIC). Office = Manager / Assistant Manager / support / liaison / project officer / operations officer — not Controller, not Duty in Charge. Mechanics = AMM, technician, refueller, and Supervisor.
